# Changelog

## [0.0.1]

### Added
- Add `snake_case()` to convert text to snake_case.
- Add `camel_case()` to convert text to camelCase.
- Add `capitalize_words()` to capitalize words.
- Add `character_count()` to count characters.
- Add `word_count()` to count words.
- Add `word_frequency()` to count word occurrences.
- Add `reverse()` to reverse text.
